# Operations Wiki

A simple Jekyll site for GitHub Pages, intended for team documents and procedures.

## Publish with GitHub Pages

1. Create a GitHub repository and upload these files.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose the branch containing this site (usually `main`) and the **/(root)** folder.
5. Save. GitHub will show the published address after the first build.

## Maintain the wiki

- Write content in Markdown files.
- Add or move links in `_data/navigation.yml` to update the sidebar.
- Copy `templates/document-template.md` for new procedures.
- Keep internal procedures in a private GitHub repository if the content should not be public.
